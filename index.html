What this is

The Maastricht Science Programme runs a set of small web tools, each built for one job: answering student questions, planning courses, running the bachelor thesis, matching tutors to courses, keeping the office calendar, and staying in touch with alumni.

This page is the front door. Pick the tool you need and it opens in the same layout you see here, so nothing has to be learnt twice. Tools marked in development are not public yet.

Who each tool is for

Students current MSP students
Supervisors thesis supervisors and advisors
Staff the MSP office and academic staff
Alumni graduates of MSP and CE
