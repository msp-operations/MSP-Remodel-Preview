How a site gets the frame

  1. Copy the msp-ui/ folder into the site (for example assets/msp-ui/). Fonts and logos travel with it, nothing is fetched from a CDN.
  2. Delete the site's old header and nav markup, and the CSS that styled them.
  3. Add the stylesheet in <head> and the two scripts at the end of <body>. The shell wraps whatever is in the body into the content column.
  4. Map the site's own colour variables onto the tokens (--navy: var(--msp-navy)) and switch its body font to var(--msp-font).
  5. Turn full-bleed heroes into a .msp-hero card, keep everything else.
<link rel="stylesheet" href="assets/msp-ui/msp-ui.css">
...
<script src="assets/msp-ui/msp-shell.js"></script>
<script>
MSPShell.init({
  title: 'MSP Tutor Registration',
  nav: [
    { label: 'Home',              hint: 'Open positions',     href: 'index.html',    icon: 'home' },
    { label: 'Register to tutor', hint: 'Apply for a course', href: 'register.html', icon: 'edit' },
    { divider: true },
    { label: 'Office login',      hint: 'Dashboard',          href: 'admin.html',    icon: 'lock' }
  ],
  footer: 'Your data stays in your browser. Nothing is uploaded.'
});
</script>

The active link is detected from the file name or hash. Single-page apps call MSPShell.setActive(href) when their view changes. The slot above the footer takes status lines or buttons through MSPShell.setMeta(html).
